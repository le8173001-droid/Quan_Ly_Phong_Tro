# Thành viên 4

Dịch vụ, Chỉ số điện nước, Hóa đơn & Thanh toán (SERVICES, METER_READINGS, INVOICES, INVOICE_DETAILS, PAYMENTS)

- `backend/` – code C++ (API)
- `web/` – giao diện (HTML/CSS/JS). Đường dẫn bên trong `web/` chính là URL trên trang (vd `web/login.html` → `/login.html`).

- `backend/m4_admin.cpp`
- `web/admin/modules/m4.js`
- `web/invoice.html`
